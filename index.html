CASE STUDIES

Production systems I own

01 · DESIGNED & BUILT · GLOBANT

STA API Gateway

Problem
The Saudi Tourism Authority's APIs lived in a legacy MuleSoft application split across 24 separate modules.
What I did
Re-implemented it as one maintainable Python gateway: request routing, authentication and token management, rate limiting, and request/response validation across downstream systems.
Outcome
One secure entry point to internal and third-party services, with centralised logging, monitoring and error handling — deployed on Docker and Kubernetes. The MOFA eVisa integration went live on it in October 2026.
  • Django
  • DRF
  • Celery
  • PostgreSQL
  • Nginx
  • Kubernetes

02 · BACKEND · STA EMPLOYEES APP

STA Employees System

Problem
Employees had to work across several enterprise systems to raise a request or find their data.
What I did
Built an integration platform over Agile, Oracle and Exchange (EWS), with a mobile app for employees and a CMS admin panel for request types, fields and configuration.
Outcome
One interface for request creation and data retrieval, tuned with Celery and PgBouncer for performance at scale.
  • Django
  • DRF
  • Wagtail
  • Celery
  • PgBouncer
  • Docker
